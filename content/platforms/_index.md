---
title: "Platforms"
description: "Open-source software and hardware built and shared by the Spring Lab."
---

We publish the tools we build so that other labs can use them, check our results, and improve on them. These include software that analyzes hyperspectral microscope video in real time, a low-cost LED system for light-activated therapy experiments, and the designs behind our microendoscope. Each tool links to the paper that describes it; please cite that paper if a tool helps your work. More code is on [the lab's GitHub](https://github.com/springlabnu).
